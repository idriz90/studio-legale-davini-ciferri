# Studio Legale Associato Davini Ciferri

Bozza statica del sito, aggiornata al 2 novembre 2026.

Questa copia contiene HTML, CSS, JavaScript, fotografie e font della versione studio-originale. Non include le precedenti proposte grafiche o documenti riservati.

## Anteprima locale

Eseguire `python -m http.server 4175` dalla cartella del repository e aprire http://localhost:4175/.

## Stato

Bozza noindex, non pubblicata. GitHub Pages non attivato. Il sito Wix e il dominio non sono modificati. I canonical puntano al dominio previsto per la futura migrazione.

Prima della pubblicazione: revisione di contenuti e informative, verifica dei recapiti e dei diritti sulle risorse, controllo visuale mobile e configurazione SEO di produzione. Il recapito di Livorno resta da confermare.

I font mantengono le rispettive licenze OFL nella cartella assets.


## Modulo richieste

Web3Forms predisposto in Contatti e Appuntamenti, attualmente disattivato. La Access Key è vuota in assets/web3forms-config.js. Nessun invio è possibile prima della configurazione. Per attivarlo occorre verificare il servizio e aggiornare le informative che riportano lo stato disattivato, poi effettuare una prova di ricezione.
